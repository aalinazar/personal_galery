How to Use Personal Galery

📁 Selecting a Directory

Enter the full path to a directory containing images or videos, or use the Browse button to navigate. The application will automatically scan all subdirectories recursively to find every media file.

Note: All media files from subdirectories will be displayed together in a single view. Folder information is shown with each file to indicate its location.

🖼️ Viewing Media

Click on any thumbnail to open the full media viewer. Use the arrow keys or navigation buttons to browse through media.

⌨️ Keyboard Shortcuts

  • ← / → - Previous/Next media
  • Esc - Close viewer
  • F - Toggle fullscreen
  • Space - Play/pause video or slideshow

🎥 Supported Formats

Images: JPG, PNG, GIF, BMP, WebP, SVG

Videos: MP4, WebM, OGG, MOV, AVI, MKV, FLV
